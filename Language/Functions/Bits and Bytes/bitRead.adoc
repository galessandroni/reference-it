= bitRead()


// OVERVIEW SECTION STARTS
[#overview]
--

[float]
=== Descrizione
Legge un bit da un numero.
[%hardbreaks]


[float]
=== Sintasi
`bitRead(x, n)`


[float]
=== Parametri
`x`: il numero da cui leggere

`n`: quale bit leggere, a partire da 0 per il bit meno significativo (quello più a destra)


[float]
=== Restituisce
il valore del bit bit (0 o 1).
