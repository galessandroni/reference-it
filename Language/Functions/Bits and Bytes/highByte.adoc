= highByte()


// OVERVIEW SECTION STARTS
[#overview]
--

[float]
=== Descrizione
Estrae il byte di ordine più alto (quello più a sinistra) di un word (o il secondo byte meno alto di un tipo di dati più grande).
[%hardbreaks]


[float]
=== Sintasi
`highByte(x)`


[float]
=== Parametri
`x`: a value of any type

[float]
=== Restituisce
byte
