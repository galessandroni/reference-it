= bitSet()


// OVERVIEW SECTION STARTS
Imposta (assegna il valore 1) a un bit di una variabile numerica.
[#overview]
--

[float]
=== Descrizione
[%hardbreaks]


[float]
=== Sintassi
`bitSet(x, n)`


[float]
=== Parametri
`x`: la variabile numerica su cui impostare il bit

`n`: quale bit settare, partendo da 0 per il bit meno significativo (quello più a destra)

[float]
=== Restituisce
Nulla
