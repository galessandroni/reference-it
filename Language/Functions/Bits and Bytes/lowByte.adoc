= lowByte()


// OVERVIEW SECTION STARTS
[#overview]
--

[float]
=== Descrizione
Estrae il byte meno significativo (quello più a destra) di una variabile (per esempio un word).
[%hardbreaks]


[float]
=== Sintassi
`lowByte(x)`


[float]
=== Parametri
`x`: un valore di qualsiasi tipo

[float]
=== Restituisce
byte
